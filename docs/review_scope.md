# 审核范围与限制

本文件说明本数据集**已经过何种检查**、**未经何种检查**，避免使用者高估其可靠性。

---

## 1. 已完成的检查（提示词层面）

由 `src/generate.py` 在每次生成时执行，并写入 `final/qa_report.json`：

| 检查项 | 说明 | 要求 |
|---|---|---|
| `triplet_integrity` | 每个 `group_id` 恰含 `clean`/`subtle`/`strong` 三档 | 全部通过 |
| `variant_tier_definition` | 三档的 `changed_field_count` 与 `rule_failure_count` 符合冻结定义 | 全部通过 |
| `group_structural_consistency` | 同组三档的载体、语言、地区、画幅、版式、划分等完全一致 | 全部通过 |
| `forbidden_visible_text` | 逐字文本中不含禁用词（AI/水印/示例等） | 全部通过 |
| `split_group_atomicity` | 同组三档落在同一集合 | 全部通过 |
| `unique_prompt_id` | `prompt_id` 全局唯一 | 全部通过 |

| 检查项 | 工具 | 说明 |

## 3. **未完成**的检查（须在使用前自行补充）

### 3.1 图像层面

**本仓库只包含提示词，不包含生成图像。** 以下字段在 schema 中预留但全部为空：

`ocr_text`、`ocr_line_boxes`、`entity_hit_rate`、`char_error_count`、
`missing_entities`、`extra_text`、`quality_grade`、`text_mask`

出图后须逐张完成 OCR 比对与质量分级。**提示词层面的抽检不能替代出图后的人工检查。**

### 3.2 语义层面

- 提示词中的文字内容为程序按内容库拼装，**未经新闻从业者或领域专家通读**；
- 内容一致性规则（`anomaly_category`）为数据集设计，**不代表任何法规或行业标准**；
- 提示词未经过"以人眼判断异常是否真的可发现"的预实验。

### 3.3 视觉层面

- 版面分区比例为模板给定值，**未经与真实截图逐一测量比对**；
- 各平台界面元素为抽象化描述，**不使用真实平台标识**，因此不能用于训练平台识别；
- 未验证生成模型能否稳定复现所声明的版面结构。

### 3.4 参考图

本仓库**未附带参考图**。理由见 `sources_and_limits.md`。

## 4. 已知的构造性局限

| 局限 | 说明 | 影响 |
|---|---|---|
| 模板化 | 3000 条由 30 个版面模板 × 内容库组合而成 | 版式多样性受模板数量约束；同模板样本的版式差异有限 |
| 档位为设计值 | `single_image_detectable` 记录的是**设计意图** | 实际可发现性须以出图后实测为准 |
| 无失败样本保留策略 | 生成失败样本的处理未在本仓库定义 | 使用方须自行定义并披露丢弃规则 |
| 语言分布不均 | zh-Hans 占 40%，en 占 36.2%，zh-Hant 占 23.8% | 与配额一致；繁体样本量较小，分层报告时须注意统计功效 |
| 地点虚构化 | 使用「真实地级市 + 虚构区/街道」 | 若检测器学到地名分布，可能引入偏置；建议在分析中检查 |

## 5. 未声明的事项

- 本数据集**不宣称**任何样本对应真实事件、真实机构或真实个人；
- 本数据集**不宣称**其内容一致性规则通过任何真实业务机构核验；
- 本数据集**不宣称**已穷尽新闻谣言类图像的载体形态。

---

## 6. 使用建议

1. **出图后先做质量分级再使用数据**，且分级阈值须与 `config/variant_rules.json` 保持一致；
2. **报告指标时同时给出固定阈值与校准后阈值**，并分开报告真实图与生成图的准确率；
3. **不要只用总准确率**，须按 `carrier`、`language`、`hazard`、`quality_grade` 分层报告；
4. 若用于跨数据集比较，须先核对该数据集是否统一了图像格式与元数据。
