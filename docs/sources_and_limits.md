# 来源说明与局限

---

## 1. 内容来源

本数据集的提示词由程序按内部内容库拼装，内容库的设计依据如下三类公开信息：

1. **公开的辟谣与事实核查通报**中归纳出的载体形态、字段结构与常见不一致类型；
2. **各平台公开的界面范式**（控件布局、信息层级、字幕形态），仅抽象为结构描述；
3. **公开新闻报道的版面形态**（电视下三分条、报纸报头、电讯抬头等）。

归纳结果体现为 `config/layout_templates_R*.json` 中的分区与文字角色定义，
以及 `config/anomaly_types.json` 中的不一致类型库。

**本仓库不附带任何原始素材、截图或参考图。**

---

## 2. 为什么不含参考图

| 原因 | 说明 |
|---|---|
| 版权 | 平台界面截图与媒体版面图的再分发权属不清晰 |
| 时效 | 平台界面改版频繁，附带参考图会迅速过时 |
| 偏置 | 若真实图与生成图来自不同采集链路，检测器会学到采集方式而非生成痕迹 |
| 合规 | 真实辟谣内容中的主体、地名与事件指向现实，不宜随数据集分发 |

如需参考图，建议使用者自行采集，并遵守 §5 的匹配要求。

---

## 3. 虚构化规则

所有主体均按以下规则虚构：

| 类别 | 规则 |
|---|---|
| 机构与媒体名 | 取自 `config/fiction_library.json` 的组合式虚构名称 |
| 地名 | 「真实地级市 + 虚构区/街道」，确保地址形式上成立且不指向现实地点 |
| 人名 | 虚构姓名库，按语言与地区分组 |
| 电话 | 保号段格式（`400-000-XXXX`、`+1-555-01XX`），不可拨打 |
| 编号 | 格式正确但虚构，年份限定 2024–2027 |
| 真实标识 | 一律排除（见 `config/constraints.json` 的 `forbidden_in_image`） |

**黑名单规则**：真实国家领导人及政治人物姓名、真实新闻机构与电视台名称、
真实政府机关名称、真实企业商号与品牌名、真实公众人物姓名、可拨打的真实电话号码、
真实证件号码，一律不得出现在生成图像中。

---

## 4. 合规边界

本研究设计**不生成**以下内容：

- 任何真实个人的肖像用于攻击性场景；
- 血腥、尸体或重伤画面；
- 性内容或涉及未成年人的内容；
- 可操作的暴恐或制造危险物的内容；
- 针对真实选举或真实选民的定向误导；
- 对真实主体（机构、企业、个人）的可被理解为事实陈述的内容。

**操作原则**：版式与文字结构保持可信，实体与场景全部虚构。
实体虚构状态记录于每条记录的 `fictional_entity_note` 字段。

---

## 5. 真实图侧的匹配要求

若使用方需为检测实验配套真实图，须满足以下匹配条件，否则检测器可能学到采集方式差异：

| 维度 | 要求 |
|---|---|
| 载体 | 与生成图同载体子类（R1–R4）与同平台族 |
| 语言 | 与生成图同语言分布 |
| 清晰度 | 与生成图同短边尺寸与压缩质量 |
| 文字密度 | 按 `text_density` 分层匹配 |
| 后处理 | 统一元数据剥离、统一重编码（见 `constraints.json`） |
| 版面 | 避免使用带官方印章、卡通形象等显著设计特征的宣传类图像 |

**特别提示**：官方辟谣类长图带有固定的设计特征（印章、卡通形象、解读框），
若直接用作真实图，检测器会学到"是否存在这些设计特征"，而非生成痕迹。

---

## 6. 未核实事项

以下事项在本版本中**未核实**，如实标注：

- 版面分区比例未与真实截图逐一测量比对；
- 生成模型能否稳定复现所声明版面结构未经验证；
- 各语言下的 OCR 召回率未实测；
- 内容库覆盖的载体形态未穷尽；
- 提示词未经领域专家通读。

---

## 7. 更新策略

- `config/` 下的配额、档位定义与质量阈值一经冻结，**不在同一版本内调整**；
- 如需调整，须递增版本号并重新计算 `release_manifest.json` 中的哈希；
- 任何调整须在 `CHANGELOG.md` 中记录原因。
